# Durusul Lughoh Jilid 1 — Aplikasi Belajar

Aplikasi web satu-file (`index.html`) untuk membantu belajar **دروس اللغة العربية لغير الناطقين بها — Jilid 1** (Dr. V. ‘Abdur-Rahim, Universitas Islam Madinah).

## Fitur
- 23 pelajaran sesuai daftar isi buku, total 375 kosakata
- Materi: ringkasan kaidah (Bahasa Indonesia) + contoh kalimat berharakat dan terjemahannya
- Kosakata dengan mode sembunyikan arti (tes diri)
- Flashcard (hafal / belum hafal) dan kuis pilihan ganda dua arah (Arab → Indonesia, Indonesia → Arab)
- Ulangan campuran dari semua pelajaran (kata yang lemah didahulukan)
- Pencarian kata (Arab dengan/tanpa harakat, atau Indonesia)
- Tombol suara (memakai suara Arab bawaan perangkat bila tersedia) + tes suara di Pengaturan
- Opsi menyembunyikan harakat, mengatur ukuran huruf, dan reset progres
- Progres tersimpan di browser (localStorage), tanpa server dan tanpa dependensi

## Cara pakai
Buka `index.html` di browser. Tidak perlu build atau instalasi.
Opsional: aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/`) untuk membukanya lewat tautan web.

## Catatan
- Kosakata dan kalimat diambil dari buku; harakat dan terjemahan Indonesia disusun untuk keperluan belajar dan belum diperiksa pengajar. Periksa kembali kata yang meragukan.
- Gambar dan soal latihan lengkap tetap ada di bukunya; aplikasi ini hanya pendamping belajar.
- Suara bergantung pada ketersediaan suara Arab di perangkat (lihat Pengaturan → Tes suara).
